# Problem Specification

The goal is to create an easy to use application for small groups to organize tournaments or other competitions. The solution should help organizers automate many parts of running a competition, such as determining matches, standings, and final results. The solution should be flexible, and accommodate different types of competitions, including things like team based vs single competition, round robin, or bracket style. It should only require one machine to run, but participants can join on different machines to do things such as review results or report matches. There should be a functionality to save and load tournaments that are in progress, and review old tournaments, allowing the application to be closed and resume where it was left off. The solution will most liekly be web based.
